# VCS CampusNotes

## Overview
CampusNotes is a collaborative repository for organizing and sharing academic notes.

## Key Features
- Subject-wise note organization
- Consistent file naming
- Git-based version control
- Collaboration through branches and pull requests

## Project Purpose
The project helps students maintain structured study materials and practice GitHub collaboration.

## Contribution Guidelines
- Follow consistent commit message conventions.
- Review changes before merging.
- Keep study materials organized and updated.
